      Approvals

      Say yes without switching windows.

      When Claude Code or Codex wants to run something, the card is in front of you, wherever you are. The exact command, the buttons, and nothing else.2

      1 needs you
      Claude Code · storefront
      wants to edit totals.ts
      iTerm2
      $ npm test -- --filter checkout
      -const total = items.reduce(sum, 0)
      +const total = round(items.reduce(sum, 0), 2)
      return format(total, currency)

      Always allow means: edit files in storefront, from now on.

      No answer in 45 s: the terminal asks instead.

      Go on, press one.

      1. The exact command.

        Not a summary. What Claude Code or Codex is about to run, word for word, before it runs.

      2. Edits, as a diff.

        A file change arrives as red and green lines, so you can see what you are agreeing to.

      3. Remembered only when it’s safe.

        “Always allow” never remembers a shell, sudo or a piped install. Those ask every time.

      4. It never blocks you.

        No answer in 45 seconds, no app, or you’re already in that terminal: the agent’s own prompt appears instead.

      Nothing leaves your Mac.

      No account, no analytics. Open Notch's only request of its own is a daily check for a new version (nothing about you is sent, and it can be turned off), and the phone remote never leaves your Wi-Fi.

      Secrets stay hidden.

      Tokens and keys are stripped from everything it shows, and it can stay out of screen shares.

      Reads what’s already there.

      Hooks and the agents’ own logs on this Mac. No Screen Recording permission; Accessibility only if you want Ghostty tabs.

      Commands you can trust.

      Hidden characters are flagged, and a new card ignores Allow for half a second, so it can’t be timed under your pointer.
