      The basics

      What is Open Notch?

      A small macOS app that lives in the MacBook notch and shows every coding agent running on your Mac: Claude Code, Codex, Command Code, Gemini CLI, OpenCode and more. It says which one is working, which one is done, and which one needs you, and lets you approve, deny or answer without switching windows.

      Is it free?

      Yes. There is no paid tier, no account and no trial.

      Does it work on a Mac without a notch?

      Yes. On a Mac without a notch, or on an external display, it draws a virtual notch hanging from the top centre of the screen. You choose the screen in Settings → Appearance.

      What does it need?

      macOS 13 Ventura or later on Apple silicon. No other software, and no Accessibility or Screen Recording permission.

      Why does macOS say it “can’t verify” the app?

      Open Notch is not notarised by Apple yet. Right-click it in Applications, choose Open, then Open again. You only do this once.

      Agents

      Which agents does it support?

      Claude Code, Codex (CLI and the ChatGPT app), Command Code (CLI and app), OpenCode, Gemini CLI, Aider, Cursor, Kimi, Pi, Goose, Amp, Antigravity, Kiro, LM Studio, Claude Desktop (Cowork) and others are found automatically. Exact state comes from Claude Code, Codex, Command Code and OpenCode; the rest show as Open while they run. Agents inside editors (VS Code, Cursor, Windsurf…), desktop agent apps, and, if you turn it on, AI chats and web coding agents in your browser tabs. Anything else can report itself with notchyctl notify. See other agents.

      Do I have to set anything up?

      No: most agents are found from their processes and their own logs. For exact states and to answer Claude Code from the notch, install its hooks once with notchyctl install claude --write; to answer Codex too, notchyctl install codex --write (Codex asks you to trust the hook once).

      Can I reply to an agent from the notch?

      Yes: hover its row and press the reply arrow. In iTerm2 and Terminal the reply is typed into the agent’s own tab and sent; in other terminals (Ghostty, Warp) it is copied and the app comes forward for you to paste, because they offer no safe way to type into one particular tab (a click on the row still takes you to the exact Ghostty tab). See Terminal and replies.

      Is there a terminal in the notch?

      Yes: the Terminal tab is a real terminal running your own shell, in the folder of the agent you were last looking at. Full-screen programs work, and it keeps running when the notch closes.

      Can I approve Codex or Command Code from the notch?

      Codex, yes: turn on its hook in Settings → Approvals (Codex asks you once to trust it) and its permission prompts show as a card you can allow or deny. Command Code offers no way for another app to answer, so its dialogs show as Needs input and a click takes you to them. Claude Code can be approved, denied and answered from the notch too.

      How does it know an agent is working? Does it watch CPU?

      Never CPU: a model call is mostly network wait, and an idle Electron app can burn 8%. It uses the best source each agent offers: hooks first, then the agent’s own conversation log, then the process list. See how it works.

      Does it show git worktrees?

      Yes. A session in a linked worktree shows the worktree’s name before its branch, so two agents on one repository are easy to tell apart. With “group by project”, the worktrees of one repository share a group.

      Approvals and safety

      What if Open Notch is not running, or I don’t answer?

      The agent asks in its terminal as usual. The hook exits at once if the app is not running, and hands the decision back after 45 seconds if nobody answers. If you are already looking at that terminal, the notch steps aside immediately.

      What does “Always allow” remember?

      Only something safe to remember: one plain command that cannot chain another, edits inside the project folder, or a named MCP tool. Never a shell, sudo, curl | sh or a compound command. Every rule is listed and removable in Settings → Approvals.

      Could an agent trick me into approving something?

      Commands with hidden characters or that are too long to read are never approvable from the notch, a new card ignores Allow for half a second so a request cannot be timed under your pointer, and secrets are removed from what is shown. See security.

      Privacy and performance

      Does it send anything anywhere?

      No. No account, no analytics, no update checks: it makes no network requests of its own. Two exceptions, both off until you turn them on: the phone notice you set up yourself, and that never carries a command, a path or file contents, and Live Claude limits, which asks Anthropic for your Claude plan’s limits with Claude Code’s own login.

      Does it work with VoiceOver and the keyboard?

      Yes, with limits it is open about. Every row is a VoiceOver button that reads who, state, what it is doing and how long ago; tabs and buttons are named, and a new “needs input” is announced. You can browse with the keyboard (arrows, Return, R, Tab, Y/D/A, Esc) after opening the notch from the menu-bar menu or ⌃⌥N. It was tested by reading the accessibility tree and sending keys, not yet in a long VoiceOver session. Details.

      Does it read my Claude login?

      Not unless you ask it to. By default the Usage tab’s Claude limits (5-hour and weekly) come from what Claude Code passes its own status-line command, and the plan type from its config file: never your e-mail, ids or login token, and nothing is fetched. If you turn on Live Claude limits (Settings → Usage), it reads Claude Code’s access token from your Keychain (macOS asks you once) to ask Anthropic for fresh figures, at most every 5 minutes, and never stores it.

      How much does it slow my Mac down?

      About 15 MB of memory at rest (up to 35 MB with many agents and the Usage tab) and under a tenth of a percent of one core while idle; opening and closing the notch costs under 15 ms of CPU. Measured against Agent Notch and Boring Notch. Hooks and logs are watched rather than polled, and nothing is polled while the screen is off or locked.

      What are the CPU and memory numbers in the notch?

      What your agents cost right now: the CPU, memory and process count of every agent and everything it started (shells, test runs, servers). CPU is counted like Activity Monitor (100% is one core). It is only measured while the notch is open on the Agents tab.

      Everything else

      Can I hide it during screen sharing?

      Yes: Settings → Advanced → hide from screen sharing keeps the notch out of screenshots, recordings and shared screens. You can also hide the commands agents run from the rows.

      How do I uninstall it?

      Run notchyctl uninstall --yes (or Settings → Advanced → Uninstall), then drag the app to the Trash. Only what Open Notch added is removed; your own hooks stay. See uninstall.

      Something is wrong. How do I report it?

      Run notchyctl diagnostics and paste the report: it describes how things are set up with no commands, addresses or secrets. Troubleshooting covers the common cases.
