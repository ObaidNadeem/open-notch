      Agents

      Other agents, editors and the web

      OpenCode, Gemini CLI, Aider and others; agents inside editors; desktop agent apps; and AI chats in your browser.

      OpenCode

      notchyctl install opencode --write

      adds a small plugin that reports when a session is working, ready or waiting for an approval. It only observes, and sends its notices one at a time, in order. OpenCode has no way to answer from outside, so a click takes you there.

      Any CLI agent

      These are found by the process scan with no setup, shown as Open with the terminal they run in: claude, codex, cmd (Command Code), agy (Antigravity), gemini, aider, opencode, cursor-agent, goose, crush, amp, droid, qwen, kimi, pi, copilot, grok, kiro-cli and more. Desktop apps are found by their app: Cursor, Windsurf, Antigravity, Kiro, LM Studio and Claude Desktop (which runs Cowork). Only Claude Code, Codex, Command Code and OpenCode give exact state; these show as Open while they run. Add your own names to ~/.notchy/agents.txt, one per line.

      To give any agent exact states, have it call:

      notchyctl notify <agent> working  --session <id> --cwd "$PWD" --message "Running tests"
notchyctl notify <agent> waiting  --session <id>
notchyctl notify <agent> idle     --session <id>
notchyctl notify <agent> end      --session <id>

      Agents inside editors

      Agents started by an editor extension have no terminal (Claude Code inside VS Code, for one). Processes without a terminal are picked up when their ancestor is an editor: VS Code, Cursor, Windsurf, Antigravity, VSCodium, Positron, Trae, Kiro. Their row shows the editor’s icon, and a click brings the editor forward.

      Desktop agent apps

      Command Code, Antigravity, Codex in the ChatGPT app, Cursor, Windsurf, Claude Desktop, LM Studio and Kiro show as Open while they run. Turn off Show desktop apps that are only open in Settings → Agents to list an app only when it has real activity to report.

      In the browser (opt-in)

      Settings → Agents → Track AI in web browsers finds AI chats and web coding agents in the tabs of Chrome, Arc, Brave, Edge, Vivaldi and Safari, through Automation (macOS asks once per browser):

      • Chats: ChatGPT, Claude, Gemini, AI Studio, NotebookLM, Perplexity, Grok, DeepSeek, Le Chat, Copilot, Poe, HuggingChat, Kimi, Qwen, Meta AI.
      • Coding agents: Claude Code, Codex, Jules, Copilot Agent, Cursor, Devin, v0, Bolt, Lovable, Manus.
      • Your own sites: one per line, optionally with a path and a name: linear.app/agent = Linear Agent.

      Only tabs on that list are kept (at most four per site, the active one first). They show as Open with the browser’s icon, and a click focuses the tab. Tabs are read when you open the notch and every five minutes, not on a timer.

      Turning an agent off

      Settings → Agents lists every kind of agent; untick one and it is never shown. From a terminal: notchyctl config disabledAgents '["gemini"]'.
