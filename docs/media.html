      Using the notch

      Media tray

      Drop screenshots, designs, PDFs and logs on the notch, and every agent can see them.

      Drag any file onto the notch (or onto its Media tab, or choose files in Settings → Media) and every agent can find it.

      Where files go

      Files are copied, never moved, into ~/.notchy/media, a folder only you can read, with an INDEX.md beside them that lists each file and what it is.

      • At most 60 files, 100 MB each.
      • Folders are refused.
      • File names are stripped of control and text-direction characters.

      On the tab, click a file to open it, drag it out to use it elsewhere, or hover and press ✕ to take it off the shelf.

      How agents find them

      • Claude Code is told automatically: its prompt hook adds the list of files to each prompt as context.
      • Codex, Command Code and Gemini CLI have no such hook. Each can be given (opt-in, in Settings → Media) one short note between markers in its own instructions file (~/.codex/AGENTS.md, ~/.commandcode/AGENTS.md, ~/.gemini/GEMINI.md) that points at the index. The file is backed up first, and turning it off restores it exactly.

      An agent only opens a file when its task needs it.

      From the terminal

      notchyctl media list
notchyctl media add ~/Desktop/screenshot.png design.pdf
notchyctl media remove <id>
notchyctl media clear
