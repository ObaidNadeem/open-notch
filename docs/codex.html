      Agents

      Codex

      Codex threads, questions and Computer Use prompts from its own rollout logs, plus its real plan limits.

      Codex needs no setup. Open Notch reads its rollout logs (~/.codex/sessions) as they are written, only the new bytes each time:

      • One row per thread, titled with the chat’s own name, showing what it is doing right now.
      • Needs input for an open request_user_input question until you reply, and for a Computer Use prompt (“Allow ChatGPT to use…?”) that has been open for 3 seconds, with Codex’s own wording.
      • Spawned threads nested under the thread that started them.
      • Plan limits: the weekly and 5-hour limits Codex itself reports, with when they reset, in the Usage tab.

      Codex in the ChatGPT desktop app and the Codex CLI are both covered.

      Codex has no hook for its questions, so those are shown but not answerable. A click on a Codex row opens that chat in the Codex app (through its own codex://threads/… address), not just the app; a spawned thread opens its parent’s chat.

      Approving from the notch

      Codex 0.160 and later has hooks like Claude Code’s. Turn on Settings → Approvals → Codex (or run notchyctl install codex --write) and Open Notch adds one hook, PermissionRequest, to ~/.codex/hooks.json. When Codex asks permission to run something, a card shows the command with Allow, Deny and Say why…, and your answer goes back to Codex.

      • Codex asks you to trust the hook once. The first time Codex starts after the hook is added or changed it says “Hooks need review”; choose Trust all and continue. Open Notch cannot do this for you, and until you do, the hook does not run.
      • If the notch is not running, or the toggle in the menu bar is off, the hook prints nothing and Codex shows its own prompt at once.
      • A command that hides characters, or is too long to read, is not allowed from the notch; it goes back to Codex.
      • There is no “always allow” for Codex yet.
      • This was verified end to end with the Codex CLI: allowing ran the command, and denying made Codex report that Open Notch denied it. The ChatGPT desktop app runs the same engine but was not tested. If you have set Codex to auto-review approvals, it may decide before it asks.
      • To remove it, use Remove in Settings, or notchyctl uninstall; your own hooks in that file stay.

      Optional: the notify hook

      Codex can also call Open Notch when a turn completes, which makes “Ready” instant. In ~/.codex/config.toml:

      notify = ["notchyctl", "hook", "codex"]
