      Reference

      Settings

      Every option, where it lives in the Settings window, and the config.json keys behind them.

      Open Settings with ⌘, from the menu-bar icon, the gear in the open notch, or notchyctl settings. It is a native window with a sidebar and a search field, and every change applies to the running notch at once.

      Settings is a separate small app inside Open Notch, launched only while it is open, so the notch itself never loads SwiftUI.

      Panes

      Pane What it holds
      General Launch at login, connecting agents, layout, sounds, keyboard, a demo
      Agents Which agents to track, desktop apps, browsers and custom sites, scan pace
      Alerts A sound per event, how long pop-ups stay, quiet hours, reminders, phone notices
      Approvals Answering from the notch, the wait, Always-allow rules, keyboard shortcuts, hooks for each agent
      Appearance Motion, width, height, count and chips, rows (branch, context, sub-agents, compact suggestions), screen, hiding, hover timing
      Media The media tray, and which agents are told about it
      Usage Tokens per day, agent and project, and a share card
      Advanced Hide commands, hide from screen sharing, welcome, relaunch, diagnostics, reset, uninstall

      config.json

      Settings live in ~/.notchy/config.json. notchyctl config prints them; notchyctl config <key> <value> sets one (a value out of range is clamped, and says so). An older file simply lacks newer keys, and a wrong value never discards the rest.

      Key Default Meaning
      intercept true Answer Claude Code’s permission prompts from the notch
      waitSeconds 45 How long a hook holds the terminal prompt back
      deferWhenFocused true Let the terminal ask when it is already in front
      shortcutsEnabled false Global keys (⌃⌥N, Y, D, A, J)
      soundsEnabled true Play sounds
      needsInputSound, questionSound, approvalSound, planSound, doneSound, arrivalSound see Alerts A sound name, or "" for none
      notifyWhenDone false Open the notch briefly when a turn ends
      needsInputSeconds 6 How long a “needs you” pop-up stays
      doneSeconds 3 How long a “finished” pop-up stays
      smartSuppress true No alert for the agent you are looking at
      quietHours, quietStart, quietEnd false, 1320, 420 Quiet hours, in minutes after midnight
      reminderMinutes 0 Remind about an unanswered request (0 is never)
      pushEnabled, pushOnlyWhenAway, pushIncludeDetails false, true, false Phone notices
      expandedWidth 560 Width of the open notch, in points
      maxHeightPercent 70 Tallest it may grow, as a share of the screen
      motion "standard" "soft", "standard" or "snappy"
      layout "list" "list" or "grid"
      hoverDelay 0.08 Seconds the pointer must rest before it opens
      hoverLinger 0 Seconds it stays open after the pointer leaves
      showCount, showActiveIcons, animateActivity true The count, the chips, and their motion
      groupByProject false Group sessions under their project
      showBranch true Branch and worktree beside a session
      showContext true The context ring
      subAgentsInOneLine false Sub-agents named on one line instead of a tree
      suggestCompact, compactPercent true, 80 The “try /compact” nudge and its threshold
      showUsage, claudeEstimate, claudeWindowTokens true, true, 0 The Usage tab, Claude’s estimate, and its window size
      mediaEnabled true The Media tab
      disabledAgents [] Agents never shown, e.g. ["gemini"]
      showDesktopApps true “Open” rows for desktop agent apps
      trackBrowsers true AI chats and agents in browser tabs
      scanInterval 3 Seconds between process scans while something is active
      display "auto" "auto", "main", "builtin" or "external"
      hideUntilActive false No notch while every agent is idle
      hideInFullScreen true Step aside when the menu bar is hidden
      hideFromScreenSharing false Keep the notch out of screenshots and shares
      showCommands true Show commands and file names (secrets are always hidden)
      launchAtLogin false Start at login
