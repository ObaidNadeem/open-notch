      Using the notch

      Alerts and phone notices

      Sounds for each kind of event, quiet hours, reminders, and short notices to your phone while you are away.

      Sounds

      Each event has its own sound, chosen in Settings → Alerts (choosing one plays it):

      Event Default
      An agent needs input Notch Pulse
      It asks a question Notch Pulse
      It wants approval Notch Pulse
      A plan is ready for review Basso
      A turn finished Blow
      A new agent started Blow

      Open Notch ships eight soft mallet-bell sounds of its own, and the macOS system sounds (Blow, Basso…) are there too. If you never changed any sound, an update moves you to these defaults; pick one yourself and all of yours stay as they are. Sounds play after the notch has moved, never before.

      Pop-ups

      When an agent needs you, the notch opens to just that agent for a few seconds. Approval and question cards stay until you answer. Optionally, it can open briefly when a turn ends, too.

      There is no alert for the agent whose terminal is already in front of you.

      Quiet hours

      Sounds off between two times (22:00 to 07:00 by default). Pop-ups still appear, so nothing is missed.

      Reminders

      Say so again when an approval or question is still unanswered after a few minutes. Off by default.

      Notices to your phone

      Open Notch can post a short notice to a web address you give it when an agent needs you or finishes: ntfy, Slack, Discord, Telegram, or any https webhook of your own.

      • Only while you are away (by default): the screen is locked or off, or there has been no input for three minutes. It never doubles what you can already see.
      • Rate-limited, so a busy agent cannot flood your phone.
      • Never carries a command, a path or file contents. A notice says which agent and what it needs; optionally it adds the project name.
      • The address is kept in a file only you can read, not in the settings file. Only https is accepted, and a redirect to http is not followed.

      ntfy on your iPhone (free, no account)

      ntfy delivers notifications to a phone from a “topic”, a name you pick. Anyone who knows the topic can read what is sent to it, so it should be long and random.

      1. In Settings → Alerts → Phone, turn on Send notices to my phone and press Create ntfy Topic. Open Notch makes a private topic (opennotch- and 20 random letters and digits) and fills in the address.
      2. On your iPhone, install ntfy from the App Store, tap +, type the topic Settings shows (Copy Topic puts it on the clipboard; with the same Apple ID it pastes on the phone), keep the server ntfy.sh, and tap Subscribe.
      3. Press Test in Settings. The notice arrives on your phone.

      With the phone remote on, tapping a notice opens the remote, so you can answer right there. A notice only ever says which agent needs you (and, if you turn it on, the project): the command stays on your Mac.

      Each person makes their own topic. Two Macs sharing one topic would see each other’s notices.
