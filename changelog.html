      Changelog

      What’s new.

      Every release of Open Notch, newest first. It never updates itself: new versions are a download away.

      v0.0.7October 2026

      Approve and answer Command Code from the notch.

      Command Code

      • Permission prompts and questions show as cards, in the CLI and the desktop app: allow, deny, always allow, and answer, multi-select and typed answers included. Edits show their diff, and always-allow rules made for Claude Code cover Command Code too.
      • Command Code’s own prompt stays on screen, and the first answer wins: answer on the notch and Command Code carries on; answer in Command Code and the card goes.
      • Say why reaches Command Code in the terminal, as your next message once it stops. In the desktop app the denial goes through without the note. Plan approvals stay in Command Code.
      • Open Notch updates its Command Code mod by itself when it starts. Restart running Command Code sessions once after updating.
      v0.0.6October 2026

      Answer your agents from your phone, and a calmer notch in macOS blue.

      Phone remote

      • Your agents and their cards on your phone, over your own Wi-Fi: allow, deny, say why, always allow, and answer questions, with edits shown as a diff. A Home Screen web app, encrypted end to end with a key only your paired phones hold; no account, nothing through the internet.
      • Pair Phone: a phone button in the open notch (and Pair Phone… in the menu-bar menu) turns the notch into a QR code. Scan it, add the page to your Home Screen, done.
      • Notices: Create ntfy Topic (Settings → Notifications) makes a private ntfy topic and shows what to do on the iPhone. With the remote on, tapping a notice opens it.

      Fixes

      • Codex’s permission cards say why it is asking, in its own words (“May I check the PR on GitHub?”), and offer Always allow with the same safety rules as Claude Code. Read-only GitHub CLI commands (gh pr view, gh run list…) can now be remembered.
      • Fewer Codex requests: a switch in Settings → Approvals (or notchyctl codex-reviewer on) lets Codex’s own reviewer approve routine sandbox escapes itself, so only the ones it is unsure of reach the notch. A request too long to review on a card goes straight to Codex’s own prompt instead of a card you can’t answer.
      • Codex no longer shows “Needs input” while it is working. Its questions don’t stop it, so one counts only once the turn has ended with it still open; stopping a turn takes its question away, and a long Computer Use task is no longer taken for an “Allow ChatGPT to use…?” prompt.
      • The onboarding guide shows each agent’s own logo (Codex and Cursor showed Command Code’s).
      • A setting changed in Settings is always picked up: one could occasionally be missed.

      Look and sound

      • macOS blue replaces the indigo everywhere: the notch, Settings, the app icon and the phone remote.
      • New default sounds: Pulse when an agent needs you, asks or wants approval; Blow when a new agent starts or one finishes; Basso when a plan is ready. If you never changed a sound you get these; a sound you picked keeps all of yours.
      • Hide the menu-bar icon (Settings → General). Open Open Notch again, or use the notch’s gear, to reach Settings.
      • A redrawn installer window: the notch, one instruction and the two icons, readable in Light and Dark Mode.

      Settings

      • Every setting lives in one place. Connecting agents moved to Agents, Alerts is now Notifications (with phone notices), the usage options moved to Usage, and General keeps only the essentials.
      • Shorter, clearer descriptions, and corrections: answering from the notch works for Claude Code, Codex and Cursor; Uninstall removes Open Notch from every agent; updates are only checked when you ask.
      • Each connection shows one action (Connect, Repair or Remove). Menus and footnotes look like System Settings, and Appearance no longer opens with a gap under its preview.
      v0.0.5October 2026

      Update with one command.

      Updating

      • `notchyctl update`, or Check for Updates in Settings → General, installs the latest release where Open Notch already is and reopens it. Settings, rules and the media tray are kept.
      • A one-line install for the terminal: `curl -fsSL https://obaidnadeem.github.io/open-notch/install.sh | sh`. It also updates any earlier version, checks the download against its published checksum, and skips the first-launch confirmation.
      v0.0.4October 2026

      Approve Cursor from the notch, and a click lands on the exact Ghostty tab.

      Approvals

      • Cursor: its terminal commands and MCP calls can be allowed or denied from the notch, with “say why” and “always allow” (Settings → Approvals → Cursor, or `notchyctl install cursor --write`). Commands that only look, like `git status`, are left to Cursor’s own auto-run, and with no answer in time Cursor decides as usual.

      The notch

      • A click on an agent running in Ghostty now selects its own tab, not just the Ghostty window. Open Notch asks once for Accessibility to do it, and leaves the tab’s title as it was.
      v0.0.3October 2026

      Model names on every row, and Claude limits that stay current if you want them to.

      The notch

      • Each Claude Code and Codex row names its model, quietly beside the branch: “Opus 5.5”, “GPT-6.1 Sol”. Read from the agents’ own logs.

      Usage

      • Live Claude limits, off unless you turn it on (Settings → Usage): when the figures Claude Code last reported are more than 5 minutes old, Open Notch reads Claude Code’s login from your Keychain (macOS asks you once) and asks Anthropic, at most every 5 minutes. The login is never stored. Off, nothing is sent anywhere.
      v0.0.2October 2026

      Claude’s real plan limits, and a new website.

      Usage

      • Claude’s 5-hour and weekly limits, as percentages with when each resets, from what Claude Code passes its own status line. No login is read and nothing is fetched. `notchyctl install claude --write` adds the status line only if you have none, and it prints nothing, so your prompt looks the same.
      • Claude’s limits show as soon as the notch opens, without waiting for the token count, and no longer hide when token estimates are off.

      Also

      • A new website and docs in the app’s own design language, with a live notch at the top of every page: hover it, answer its cards, drop a file on it, or press ⌃⌥N.
      • Releases are built and published automatically, and every release binary is checked to carry none of the source.
      v0.0.1October 2026

      The first release: every coding agent on your Mac, in the notch.

      The notch

      • Compact chips for agents that are working or need you, and a count that rolls.
      • An open list of every agent, newest change on top, with the app it lives in, what it is doing, its branch, context ring and status.
      • Linked git worktrees named beside the branch, so two agents on one repository are easy to tell apart.
      • What the agents cost: CPU, memory and process count of every agent and everything it started, measured only while you look.
      • Status badges that only shout when it matters: Working turns, Needs input is orange, Ready is green, Idle and Open are an outline.
      • Rows settle in one after another as the notch opens; hovering a row shows where a click will take you.
      • Sub-agents as a tree or on one line, a grid view, and grouping by project.
      • A Terminal tab: your own shell in the notch, in the folder of the agent you were looking at. Full-screen programs work.
      • Reply to an agent from its row: straight into its iTerm2 or Terminal tab, or copied for any other terminal.
      • A click on a Codex row opens that chat in the Codex app, not just the app.
      • VoiceOver: rows, tabs and buttons are named and pressable, with a Reply action, and a new “needs input” is announced. The quietest text now meets 4.5:1 contrast.
      • Every page keeps the same gap at the bottom as at the sides, so the cards’ corners follow the notch’s own curve.

      Approvals and questions

      • Allow, deny, always allow and say why for Claude Code, with edits shown as a diff.
      • Codex permission prompts can be allowed or denied from the notch too, through Codex’s own hook (Codex asks you to trust it once).
      • Questions answered from the notch, multi-select included.
      • Commands that hide characters or are too long to read are never approvable from the notch.
      • Keyboard shortcuts with no Accessibility permission.
      • Browse agents with the keyboard: arrows, Return to go, R to reply, Tab for pages, Y/D/A on a card, Esc to hand the keys back.

      Agents

      • Claude Code, Codex, Command Code and OpenCode connected through hooks, logs, a mod or a plugin.
      • Pi is recognised alongside Kimi, Cursor, Gemini CLI, Aider, Kiro, LM Studio and Claude Desktop.
      • Every CLI agent in a terminal, agents inside editors, desktop agent apps, and AI chats in browser tabs.

      Also

      • Usage tab: Codex’s real limits, Claude’s plan, and token estimates from each agent’s own logs.
      • Media tray: drop files on the notch for every agent to see.
      • Sounds per event, quiet hours, reminders, and notices to your phone while you are away.
      • notchyctl: install, notify, respond, config, media, usage, diagnostics, demo and uninstall.
