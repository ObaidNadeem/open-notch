      Changelog

      What’s new.

      Every release of Open Notch, newest first. It never updates itself: new versions are a download away.

      v0.0.1October 2026

      The first release: every coding agent on your Mac, in the notch.

      The notch

      • Compact chips for agents that are working or need you, and a count that rolls.
      • An open list of every agent, newest change on top, with the app it lives in, what it is doing, its branch, context ring and status.
      • Linked git worktrees named beside the branch, so two agents on one repository are easy to tell apart.
      • What the agents cost: CPU, memory and process count of every agent and everything it started, measured only while you look.
      • Status badges that only shout when it matters: Working turns, Needs input is orange, Ready is green, Idle and Open are an outline.
      • Rows settle in one after another as the notch opens; hovering a row shows where a click will take you.
      • Sub-agents as a tree or on one line, a grid view, and grouping by project.
      • A Terminal tab: your own shell in the notch, in the folder of the agent you were looking at. Full-screen programs work.
      • Reply to an agent from its row: straight into its iTerm2 or Terminal tab, or copied for any other terminal.
      • A click on a Codex row opens that chat in the Codex app, not just the app.
      • VoiceOver: rows, tabs and buttons are named and pressable, with a Reply action, and a new “needs input” is announced. The quietest text now meets 4.5:1 contrast.
      • Every page keeps the same gap at the bottom as at the sides, so the cards’ corners follow the notch’s own curve.

      Approvals and questions

      • Allow, deny, always allow and say why for Claude Code, with edits shown as a diff.
      • Codex permission prompts can be allowed or denied from the notch too, through Codex’s own hook (Codex asks you to trust it once).
      • Questions answered from the notch, multi-select included.
      • Commands that hide characters or are too long to read are never approvable from the notch.
      • Keyboard shortcuts with no Accessibility permission.
      • Browse agents with the keyboard: arrows, Return to go, R to reply, Tab for pages, Y/D/A on a card, Esc to hand the keys back.

      Agents

      • Claude Code, Codex, Command Code and OpenCode connected through hooks, logs, a mod or a plugin.
      • Pi is recognised alongside Kimi, Cursor, Gemini CLI, Aider, Kiro, LM Studio and Claude Desktop.
      • Every CLI agent in a terminal, agents inside editors, desktop agent apps, and AI chats in browser tabs.

      Also

      • Usage tab: Codex’s real limits, Claude’s plan, and token estimates from each agent’s own logs.
      • Media tray: drop files on the notch for every agent to see.
      • Sounds per event, quiet hours, reminders, and notices to your phone while you are away.
      • notchyctl: install, notify, respond, config, media, usage, diagnostics, demo and uninstall.
      • Claude’s real 5-hour and weekly limits in the Usage tab, from what Claude Code passes its own status line: no login read, nothing fetched.
      • A new website and docs in the app’s own design language, with a live notch at the top of every page: hover it, answer its cards, drop a file on it, or press ⌃⌥N.
